# LinguaScore Mobile

Expo-приложение (русский интерфейс) для игрового оценивания произношения.

## Что реализовано
- Регистрация и вход
- История оцениваний
- Запуск новой попытки
- Прохождение 10 слов по шагам
- Случайный балл (1..10) для каждого слова через backend
- Итоговый балл и сохранение в БД
- Анимированный playful UI

## Запуск
```bash
bun install
cp .env.example .env
EXPO_PUBLIC_API_URL=http://127.0.0.1:3000 bun run start
```

Для телефона в одной Wi-Fi сети укажите IP вашего компьютера, например:
```bash
EXPO_PUBLIC_API_URL=http://192.168.1.50:3000 bun run start
```

## Скрипты
- `bun run start`
- `bun run android`
- `bun run ios`
- `bun run web`
- `bun run lint`

## Важно
Сначала запустите backend из папки `backend`, затем mobile.

Для реальной оценки произношения на устройстве дайте приложению доступ к микрофону.
